# Ten-minute Copilot demo

| Time | Demonstration |
|---|---|
| 0:00–1:00 | Open the JFK workspace and show the case evidence inventory. |
| 1:00–3:00 | Open the saved Q&A about the ASDE-X alert and controller action. Expand the cited PDF-page excerpt. Show a pending finding and the reviewer confirmation required to accept it. |
| 3:00–5:00 | Open the Hazard Register, run the deterministic risk screen and show how a mitigation must link to an accepted hazard. |
| 5:00–6:30 | Switch to Austin. Show the operational go-around evidence, the earlier wrong-aircraft result and its review disposition. Select JFK in the comparison tool to show case separation. |
| 6:30–8:00 | Show the Goa evidence intake and final-test lock. Once the independent test has run, show its sealed evaluation log and separately scored results. |
| 8:00–9:00 | Compile the six-section PDF from findings already accepted by the demo reviewer. Open an evidence reference and show the review record. |
| 9:00–10:00 | Inspect the trace for retrieval mode, citation checks, latency and token counts. Summarize the latest measured evaluation, any abstentions, and the human decision boundary. |

CPU-only Qwen3 can take several minutes. Use saved executions for the time-boxed walkthrough and start one short live question early.
