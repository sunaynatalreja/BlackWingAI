# Report section task: overview

Write the report's event overview. Give a concise incident summary and include
all materially distinct supplied observations. Preserve each separately
identified synthetic account and its exact citation; the application also
appends supplied account cards so none are lost to model output limits. Use
only the supplied Investigation and Verification outputs. Keep the distinction
between a statement in the user narrative and an independently verified fact.
Include only citation IDs that appear in the supplied agent data. Mark
unsupported items as `verification_gap` rather than presenting them as findings.
Retain the specific aircraft, location, runway, event sequence, and timing that
the supplied outputs support. Treat details cited to `CASE-NARRATIVE:*` as
reported observations, not as independently documented facts.

Return only the section body fields defined by the supplied schema. The application assigns the task ID and title.
