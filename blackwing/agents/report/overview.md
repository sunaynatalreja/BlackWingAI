# Report section task: overview

Write the report's event overview. The summary becomes the Executive Summary
shown at the top of the report: write 2–3 concise sentences (about 45–65 words,
typically one or two lines longer than a one-sentence summary). State what
happened, the key supported sequence and outcome, and the most important
uncertainty. Use plain language and preserve attribution; do not present an
inference as a confirmed finding. Then list up to five important observations.
Use only the supplied Investigation and
Verification outputs. Keep the distinction between a statement in the user
narrative and an independently verified fact. Include only citation IDs that
appear in the supplied agent data. Mark unsupported items as
`verification_gap` rather than presenting them as findings.
Retain the specific aircraft, location, runway, event sequence, and timing that
the supplied outputs support. Treat details cited to `CASE-NARRATIVE:*` as
reported observations, not as independently documented facts.

Return the requested section schema with `task_id` set to `overview`.
